# 直播答题宣传图 · Adobe XD 交付

- `live-quiz-promo.xd`：Adobe XD 原生本地文档，画板尺寸 1240 × 1184 px。
- 文档保留原始设计图作为画板中的可替换图像层，适合在 Adobe XD 中继续标注、切图或覆盖编辑。
- 仓库中的 `output/sketch/live-quiz-promo.sketch` 提供了按区域和 UI 元素分组的可编辑重建版本；Adobe XD 可直接导入 Sketch 文件后继续细化。

文件采用 XD 的标准 DCX/ZIP 容器结构，包含 manifest、画板场景图、资源、交互描述、预览图和缩略图。
