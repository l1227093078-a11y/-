# 超时自动退单商品 · 手机 H5 原型

把用户提供的11月4日表格转为按“组织 → 门店 → 商品”浏览的手机页面。延续既有绿色原型的字体、卡片、筛选和底部浮层风格。

## 使用

- `index.html` 是独立HTML，所有样式、交互、图标和示例数据内嵌，无CDN依赖。
- 本目录执行 `npm run dev -- --host 0.0.0.0 --port 4173 --strictPort`，通过 HTTP 浏览。无需安装运行依赖。
- 修改 `src/data.json`、`src/style.css`、`src/app.js` 后执行 `npm run build`。
- `npm test` 需要 Playwright 与 Chromium。通过 `CHROME_PATH` 可指定浏览器路径；测试自带临时HTTP服务，无需预先启动页面。

## 交互与口径

1. 关联组织默认全部组织，统计日期默认今日。今日以北京时间（Asia/Shanghai）计算。
2. 组织为左右分栏：左侧市场/仓库，右侧门店。点击名称切换列表，勾选组织批量选择，支持跨组织多选、全选、半选与实时计数。
3. 组织重置清空本次草稿，至少选一间门店后可确定；关闭、遮罩或Escape不应用草稿。
4. 首页统计日期下方不显示快捷标签。日期浮层右上角提供“今日、明日、近一周”；近一周为今日起连续7天（含今日）。支持依次点击日历选择起止日期，包含首尾；不再展示“已选几天”或底部日期输入框，点击确定后应用。
5. 过去日期禁用，上一月不能越过当前月；开始、结束日期均不可早于今日，开始不可晚于结束，缺失日期也会阻止确认。支持跨月、跨年区间；关闭不应用草稿，重置恢复今日单日。
6. 汇总模块标题为“数据合计（去重）”，“（去重）”使用较小的灰字。下方两张并排浅绿卡分别展示“商品种类”和“关联门店”，每卡包含绿色数值、单位、标题和右侧上下居中的青绿色立体购物篮/店铺图标（64px，窄屏58px，无外框），卡片最小高度88px（窄屏84px）。首页内容区与内页统一使用浅灰绿色底色，市场卡保留白色。商品种类按当前日期与组织范围跨门店去重，示例10种；关联门店12家。统计计算、市场卡及内页口径不变。
7. 首页不再显示“商品明细”标题和搜索框，改为市场/仓库卡片，显示组织名称、关联门店数量与去重商品种类数；点击进入该组织的门店数据页。
8. 内页继承首页已确认的关联组织、日期区间；上方仅搜索当前组织下的商品名称或编码，不匹配门店名称、不混入其他组织。长门店商品卡可展开/收起，搜索显示全部命中。
9. 内页返回保留首页筛选和滚动位置；支持页面返回、浏览器后退/前进和直接打开市场hash链接。
10. 未来日期无数据时显示空状态，不伪造计划或成功记录。

## 示例数据

按截图可见区域人工整理2个组织、12家门店、24种商品条目、10种商品：廊坊市场8家/16项，临汾仓库4家/8项。商品名称与编码为截图转录的演示值，需以业务接口数据为准。为便于演示日期限制，示例数据绑定到每次打开页面时的今日；并非每日真实采集结果。当前仍为演示原型，未接入实际业务接口。

## 实际使用前的接口接入

当前是完整前端交互原型，**尚未接入每日自动退单数据、登录账户及后端接口**。不执行退款或退单操作。

接入时需由后端：

- 按登录账户返回可见组织和门店，查询时再次验证门店权限；
- 提供按日期区间查询的自动退单商品列表及权威统计结果；
- 使用服务端北京时间校验开始、结束日期均不得早于今日且起始顺序合法，不能只依赖前端和设备时间；
- 确定未来日期的数据来源、生成时机以及字段口径。

前端 `getRows()` 为示例数据读取入口，可替换为接口请求；其余筛选状态与展示可继续复用。接入业务数据后才可替代每天手工整理表格。

## 验证

浏览器检查320×600、390×844、1280×1000：汇总、编码去重、组织多选及半选、确认/取消、仅商品搜索、商品展开、过去日期拦截、空缺/倒序区间、跨月跨年区间、单日、空状态及键盘关闭。截图与设计检查见 `previews/`、`design-qa.md`。

区间统计以已提供的日期数据为准：示例仅含今日记录，区间包含今日时展示对应示例条目，纯未来区间为空，不人为复制数据到区间内的每一天。

汇总图标按用户参考风格生成，为透明背景的青绿色立体购物篮与店铺，源文件位于 src/assets/，HTML 内嵌，无需额外请求。其余图标许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
