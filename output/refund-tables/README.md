# 退款金额统计 · 表格明细对比版

从既有退款金额统计原型创建的独立版本，保留原站点 `/refund.html`，本版本部署至 `/refund-tables/`。

四个多维度明细统一为五列表格：名称、退款金额合计、系统/手动超时退单、未取货仅退款、已取货退货退款。金额显示两位小数、单位元，按合计降序，数据来自原页面已确认的筛选条件。

- 商品、产品经理：按对应维度聚合展示。
- 商品分类：默认收起一级分类；点击名称或加减图标，在当前表格展开全部二级分类，各一级独立控制。没有匹配退款的二级分类显示0，不引入筛选范围外的金额。
- 市场/门店：点击市场名称或加号，打开手机内从底部浮出的“门店统计”，展示该市场当前筛选范围内的门店及退款金额；关闭、遮罩和Escape返回原市场表格，保留首页筛选。
- 窄屏表格可左右滑动，名称列固定；分类展开/收起保留横向浏览位置，新进入明细页从首列开始。
- 沿用原首页筛选、趋势、规则说明和右侧需求文档。仅在新版本中将文档的分类和市场交互说明同步为本次表格/浮窗行为。

## 使用

`index.html` 为可独立运行的HTML，样式、脚本、图标、演示数据均内嵌。电脑端保留左侧手机、右侧文档布局；窄屏只显示交互原型。

- `npm run dev -- --host 0.0.0.0 --port 4173 --strictPort`
- `npm run build`：由 `src/template.html`、`src/table.css`、`src/table.js`、`src/table-icons.json` 生成首页。
- `npm test`：Playwright/Chromium验证320/390/1280px，包括四维金额、分类展开、门店浮窗、焦点与键盘、筛选继承、空状态及横向滚动。
- `python3 src/package.py`：导出独立代码包并校验文件清单。

数据仍为原页面的演示流水（基准日期2026-10-22），未接入真实退款接口或登录权限；不执行退款操作。表格列名按本次参考图调整，并同步库里最新的退款类型和规则文案；沿用原型三类演示流水，未新增独立的手动超时退单数据源。真实账户权限与退款口径需由业务后端校验和提供。

图标采用Tabler Icons 3.35.0，许可见 THIRD_PARTY_NOTICES.md。

直接HTML入口：`/refund-tables-preview.html`。构建时同时生成目录首页与该独立入口，后者不依赖目录首页解析；原`/refund.html`不修改。
