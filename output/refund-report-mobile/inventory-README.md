# 库存统计 H5

根据 2026-10-26 提供的库存原型开发的可交互前端。纯 HTML/CSS/JavaScript，无构建依赖；图标和商品缩略图内嵌，可离线运行。

## 打开与交付

- [经营报表入口](https://l1227093078-a11y.github.io/-/?v=20261026-inventory)：原门店/仓库库存入口合并为“库存统计”，已有退款统计保留。
- [直接打开库存统计](https://l1227093078-a11y.github.io/-/inventory.html?v=20261026-inventory)。
- [下载完整 H5 代码包](../inventory-h5.zip)。解压后用浏览器打开 `index.html`；也可在本目录运行 `python -m http.server 4182` 后访问 `http://localhost:4182/`。

库存页面是 `inventory.html`；经营报表为 `index.html` / `reports.html`；退款页为 `refund.html`。跳转时请保留文件的相对目录。

## 已实现交互

| 功能 | 行为 |
| --- | --- |
| 库存列表 | 按当前条件汇总；切换全部、标品、非标品；两类均显示产品经理；加载更多；无匹配时显示空态 |
| 商品 | 支持名称、演示商品编码（如 p04）、SKU 编号搜索；多选；仅显示已选数量 |
| 分类 | 两级分类；一级全选/取消、半选、展开收起；二级单独勾选；与按商品模式互斥 |
| 产品经理 | 搜索、多选、全选、取消全选、一键全选；搜索保留已选；仅显示已选数量 |
| 门店筛选 | 左列分仓、右列对应门店；可切换分仓、按分仓批选、逐店多选及全选 |
| 仓库筛选 | 分仓多选、全选/取消全选、一键全选 |
| 仓库+门店 | 同时选择分仓自身库存及关联门店库存；分组批选、独立选择、半选；两类选择独立计算，不把空选自动解释为全部 |
| 经理明细 | 商品涉及多个分仓时，“查看分仓明细”打开底部抽屉，展示各分仓经理及当前口径库存 |
| 操作一致性 | 筛选均复用同一个底部抽屉；确定才应用；关闭/遮罩/Esc 放弃未确认修改；重置清空临时选项；组织至少选择一项 |
| 整体重置 | 恢复当前账号默认可见范围、全部商品、全部经理、全部类型 |
| 无障碍及适配 | 原生按钮、键盘操作、复选状态/半选状态、弹层焦点约束；支持 320px 及以上手机宽度，短屏列表可滚动且操作按钮固定可达 |

未知账号参数进入无授权状态，不回退为总仓。候选项、搜索、全选、汇总及经理明细均按演示账号范围计算。门店范围的分仓/供应商信息仅使用所选门店关联的授权分仓。

**这是前端演示版，不是真实鉴权系统。** 演示数据随 HTML 提供，不能靠前端隐藏或 URL 参数保护真实业务数据。生产环境必须由登录会话及后端权限服务确定账号和授权范围，所有查询、候选项、搜索、全选、汇总和下钻接口均需服务端鉴权；前端不得指定他人身份或扩大范围。

## 库存口径与数据说明

- 当前使用 12 个演示商品、5 个分仓、10 家门店、4 位经理；商品名称、数量、SKU、归属均为演示，不代表真实业务数据。
- 同一商品按分仓设置不同产品经理；选中经理后只计算该经理归属的库存。
- 门店模式：显示所选门店库存、其关联分仓库存及供应商实际库存。每个关联分仓只计算一次。
- 仓库模式：显示所选分仓库存、供应商实际库存。仓库+门店模式：分别显示各自所选组织的库存。
- 经理明细不将供应商库存计入自有库存；门店模式展示门店库存，仓库模式展示分仓库存，合并模式展示所选分仓+门店库存。
- 原图部分字段和说明字号较小，本版按“门店库存 / 分仓库存 / 供应商实际库存”实现；这些字段和授权映射需按实际后台业务口径确认。

## 代码与重建

```text
inventory.html                 可直接运行的完整页面
inventory-src/inventory.css    样式
inventory-src/inventory.js     状态、演示数据、筛选和汇总逻辑
inventory-src/build.py         生成单文件 HTML
inventory-src/verify.cjs       Playwright 交互验证
```

修改 JS/CSS 后，在本目录运行 `python inventory-src/build.py`。构建脚本从现有 `refund.html` 复用内嵌 Tabler 图标和 Twemoji 缩略图；需保留该文件。没有网络请求或 CDN 依赖。

验证需安装 Node.js、Playwright 和 Chromium，运行：

```bash
python -m http.server 4182
# 另一个终端，设置实际 Chromium 路径（默认 /usr/bin/chromium）
node inventory-src/verify.cjs
```

如使用其他端口，通过 `INVENTORY_BASE_URL` 设置测试地址。`CHROME_PATH` 可指定浏览器路径。

## 后端接入边界

在 `inventory-src/inventory.js` 中，以实际接口替换 `PRODUCTS`、`STOCKS`、`STORE_STOCKS` 和演示 `ACCOUNTS`。建议接口分别提供：当前会话授权信息、商品/分类候选项、经理候选项、可见组织树、库存列表及经理分仓明细。权限身份由后端会话决定，列表/明细返回已授权且已聚合的结果；分页、检索和库存时点由同一服务口径处理。

图标及缩略图许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本次没有新增图片素材来源。
