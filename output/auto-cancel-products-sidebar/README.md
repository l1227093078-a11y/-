# 超时自动退单商品统计 · 左右分栏对比版

独立版本，不覆盖原列表版。首页仍为经营报表，新入口进入统计页，再点击市场进入左右分栏的门店商品页。直接对比入口：`stats.html#market-g1`。

- 顶部日期、关联门店、商品种类以三栏浅绿色信息块展示，值在上、标签在下，数字随当前搜索结果更新。
- 左侧展示当前市场、日期和已确认关联组织范围内的门店，选中门店以白底、绿字和绿色边线标识。
- 右侧门店信息直接放在页面底色上、使用常规字重，商品列表独立为完整白色圆角卡片，商品名称加粗。仅展示选中门店的商品名称、编码、种类数与预留箭头；默认选中第一家门店，商品全部显示。
- 左侧门店与右侧商品独立纵向滚动；切换门店时保留左栏浏览位置，右侧回到顶部。
- 搜索支持门店名称、商品名称与编码。门店命中展示该店所有商品；商品命中只显示相应条目。当前店不在结果中时自动选中第一家匹配门店，清空后恢复门店列表。
- 返回统计页保留已确认日期与组织筛选；日期仅支持今日及未来，区间、组织多选与原版本一致。
- 示例数据为前端演示，未接入登录权限或真实业务数据接口；后端必须按账号权限返回和校验可见组织、门店。

## 开发与验证

`npm run dev -- --host 0.0.0.0 --port 4173 --strictPort` 启动预览，`npm run build` 生成独立 `index.html` 与 `stats.html`；`npm test` 运行320/390/1280px浏览器验证。修改仅在本目录源文件生效。

`python3 src/package.py` 生成 `../auto-cancel-products-sidebar-h5.zip`。图标来源及许可见 THIRD_PARTY_NOTICES.md，生成的绿色立体汇总图标位于 src/assets/。
