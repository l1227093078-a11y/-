| 模块 | 功能 |
| --- | --- |
| 推荐列表 | 商品图片、名称、编号、价格、分类、排序值、门店、设置时间、显示状态；初始全部 13 项、显示中 8 项、已移至库站 5 项 |

| 管理 | 勾选、全选/取消全选、已选数量、批量移除；已移除记录不可重复移除 |
| 移除 | 单项/批量确认弹窗；取消不修改；确认后对应门店停止展示，记录保留在“已移至库站” |
| 排序 | 按门店独立置顶与调整排序值；数值从 1 开始，支持上下步进和校验；添加页也可调整所选商品顺序 |

| 选择商品 | 仅展示启售商品；名称/编号搜索；两级分类筛选；支持常规、组合、套装；多选、数量、取消与完成 |
| 保存 | 对每个所选门店保存所选商品；同店同商品不重复新增；再次添加已移除商品会恢复展示；数据按演示账号保存在浏览器中 |
| 页面及适配 | 列表/添加/商品选择页面可切换，支持浏览器后退；浮层支持关闭、遮罩、Esc 与焦点约束；320px 起手机适配 |

## 预览及本地运行

全部图片、图标、样式和脚本已内嵌，没有 CDN 请求。推荐使用下面的本地 HTTP 预览；允许访问本地文件的浏览器也可尝试打开 `index.html`。

也可在当前目录运行：

```bash
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

然后访问 `http://localhost:4173/`。不需要执行 npm install。开发服务器提供无缓存静态响应；按 Ctrl+C 停止。

配置保存在当前浏览器的 localStorage，刷新仍保留；清除站点存储可恢复初始演示数据。若浏览器禁止本地存储，操作会提示无法保存，当前会话内仍可体验。

| 无效参数 | 无授权状态 | 不返回推荐列表，不允许添加 |

候选门店、搜索、全选、列表、移除、排序与新增均按当前演示范围执行，各账号的本地存储分开。分类与商品数量根据演示商品库计算；分类共 15 个二级分类，启售商品 19 个，因此部分数量与原型示例不同。

**此版本没有接入真实登录和后端。** URL 的 account 参数只用于体验，不可作为生产授权依据。演示商品和推荐记录随 HTML 提供，前端隐藏不能保护真实数据。生产接口必须根据登录会话解析权限，并对候选门店、商品、列表查询及每次添加/移除/排序在服务端鉴权。

## 规则说明

- “移除”仅停止对应门店首页推荐，不删除商品本身。列表中的已移除记录可通过再次添加恢复。
- 同一门店+商品为唯一配置；批量添加会跳过已显示的配置，恢复已移除的配置，按所选顺序追加新配置。
- 排序按门店独立生效，不影响其他门店。每次排序后从 1 连续编号，已移除记录保留排序位置，支持恢复。
- 分类、门店筛选未选表示当前账号范围内不限该维度；添加页门店未选则不能保存。
- 显示中的商品才能在管理中勾选移除。全选仅选择当前搜索、筛选和状态范围内可移除的项。
- 商品名称、价格、编号、数量、门店及时间均为演示，不代表实际售卖信息。设置时间以 Asia/Shanghai 显示。

## 源码结构与构建

```text
index.html               可独立运行的最终 H5
src/app.js               数据、状态、筛选、管理、保存及排序逻辑
src/style.css            页面与浮层样式
src/assets.json          已内嵌的授权图片及图标
src/shell.html           页面壳
src/status.html          沿用的状态栏
src/build.py             生成单文件 H5
src/dev.cjs              无依赖开发服务器
src/verify.cjs           Playwright 交互检查
src/capture.cjs          生成预览截图
previews/                实际浏览器截图
```

修改源码后执行 `npm run build`（需要 Python 3）。构建不访问网络，产物为 `index.html`。

测试需要 Node.js、Playwright 与 Chromium。在本地服务器运行时执行：

```bash
H5_BASE_URL=http://127.0.0.1:4173 CHROME_PATH=/usr/bin/chromium npm test
```

本环境已验证 320/375/485px 宽度、320×600/667 短屏、三个演示账号及无授权状态。测试结果见 `src/verification.json`，界面检查见 [design-qa.md](design-qa.md)。

## 后端接入

以会话接口提供的授权门店替换 `ACCOUNT_SCOPES`，以业务商品接口替换 `CATALOG`，以推荐查询、幂等保存、移除和门店排序接口替换 `readRecords`、`persist` 及对应写操作。服务端应返回最终排序和状态，批量写入需校验门店范围、商品启售状态及同店商品唯一约束。
